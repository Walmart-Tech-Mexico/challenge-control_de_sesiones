# Control de sesiones

**Nivel:** Intermedio

## Descripción
Gestionar múltiples sesiones de usuario en una tienda online.

## Objetivo
Implementa una solución en Java que cumpla con la lógica descrita. Usa la plantilla `Main.java` para comenzar.

## Cómo empezar
1. Clona este repositorio.
2. Dirígete a la carpeta `Control_de_sesiones`.
3. Abre `Main.java` y escribe tu solución.
4. ¡Comparte tu solución con la comunidad!
